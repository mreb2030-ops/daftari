# دفتري: محاسبة شخصية لأندرويد

تطبيق أندرويد مجاني يعمل بلا إنترنت، وبياناته على جهازك فقط.

## ما الذي يفعله
- **دخول:** رمز من 6 أرقام، وبصمة اختيارية. قفل تلقائي عند الخروج من التطبيق. إيقاف مؤقت بعد 5 محاولات خاطئة.
- **الحسابات:** صندوق، بنوك، أصول (سيارة، عقار، ذهب…)، التزامات (قروض، بطاقات، ديون).
- **العمليات:** إيراد، مصروف، مشتريات (أغراض أو أصل، نقداً أو آجل)، تحويل بين الصندوق والبنوك، التزام جديد، سداد التزام. كل عملية لها رقم قيد.
- **التقارير:** قائمة الدخل، المركز المالي (الأصول = الالتزامات + حقوق الملكية)، التدفق النقدي، كشف حساب بالرصيد الجاري. بحسب شهر أو سنة أو كل الفترات. تصدير CSV.
- **البيانات:** نسخة احتياطية JSON، استعادة، تصدير كل العمليات CSV.

## كيف تحصل على ملف APK (مجاناً)

### الطريقة 1: بدون تثبيت أي برنامج على حاسوبك (GitHub)
1. أنشئ حساباً مجانياً في github.com، ثم مستودعاً جديداً **خاصاً** (Private).
2. ارفع محتويات هذا المجلد كلها (Add file ← Upload files). ملف `.github/workflows/build-apk.yml` يجب أن يُرفع أيضاً. إن لم يظهر المجلد المخفي، استخدم GitHub Desktop أو الأمر `git push`.
3. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**. ينتهي البناء خلال 5 إلى 10 دقائق.
4. افتح التشغيل الناجح ونزّل **daftari-apk** من الأسفل، وفك الضغط لتجد `app-debug.apk`.

### الطريقة 2: على حاسوبك
يلزم Node.js 22 وJDK 21 وAndroid Studio.
```
npm install
npm run apk
```
الملف الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`. أو افتح مجلد `android` في Android Studio.

## التثبيت على الجوال
انقل الملف إلى جوالك وافتحه، واسمح بالتثبيت من المصدر عند السؤال. هذا ملف تجريبي موقّع بمفتاح التطوير، وهو مناسب للاستخدام الشخصي. النشر في متجر Google Play يحتاج توقيع إصدار (release) وحساب مطوّر.

## تجربة الواجهة في المتصفح
```
npm install
npm run serve        # ثم افتح http://localhost:8765
npm run test:ledger  # اختبار منطق المحاسبة
```
في المتصفح لا تتوفر البصمة، وتُحفظ البيانات في localStorage.

## أمان وحدود يجب أن تعرفها
- الرمز يُخزَّن مُجزّأً (PBKDF2). البصمة تعتمد على Android Keystore.
- **البيانات نفسها غير مشفّرة** داخل مساحة التطبيق المعزولة. لا يصل إليها تطبيق آخر على جهاز غير مكسور الحماية.
- **نسيان الرمز لا يمكن استرجاعه.** الحل هو مسح البيانات والبدء من جديد، ثم استعادة نسخة احتياطية. خذ نسخة احتياطية بانتظام وأرسلها لنفسك.
- لم أجرّب التطبيق على جهاز أندرويد حقيقي، لأن بيئة البناء عندي لا تصل إلى أدوات أندرويد. اختبرت المنطق المحاسبي والواجهة وسيناريوهات الدخول في المتصفح. أمور البصمة ومشاركة الملفات تُختبر على جوالك أول مرة.
